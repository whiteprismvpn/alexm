# AlexM — one-page resume

Современное персональное резюме на Astro: одностраничная прокрутка, фиксированная правая навигация на desktop и нижняя навигация на мобильных устройствах.

## Редактирование

Весь контент сайта находится в `src/data/profile.ts`. Там можно заменить имя, роль, email, город, описание, опыт, навыки/услуги, кейсы и ссылки на соцсети.

## Локальный запуск

```bash
npm install
npm run dev
```

## Деплой

Подключите репозиторий к Cloudflare Workers & Pages. Команда сборки: `npm run build`. Каталог результатов: `dist`. Для production выберите `main`, а ветку `feature/modern-onepage-resume` используйте для preview перед merge.
